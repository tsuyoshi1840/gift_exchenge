ボタン背景画像の置き場所
========================

ここに置いた画像が、メイン画面のボタンの背景に薄く表示されます。

  participant_count.png  … 緑の「参加予定人数」ボタン
  lottery_button.png     … 赤の「抽選をはじめる」ボタン
  result_button.png      … 結果画面の「抽選開始／次の抽選を開始」ボタン

・同じ名前の .gif を置くと、PNGより優先されてアニメーションします。
・ボタンの大きさは 400×65 です。くっきり表示したいときは倍の 800×130 で作ってください。
・透過の濃さは image_button.py の DEFAULT_IMAGE_OPACITY（0.0〜1.0）で変えられます。
・今入っている画像は仮素材です。差し替えるときは同じファイル名で上書きしてください。
・ファイルを消すと、画像なし（色だけ）のボタンに戻ります。
